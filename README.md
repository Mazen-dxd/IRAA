# IRAA — أزياء عربية معاصرة

واجهة عربية أولاً لعلامة IRAA. الموقع مباشر على GitHub Pages ويعرض الصورة الأولى التي أرسلتها صاحبة العلامة. لا تظهر منتجات للبيع قبل اعتماد الاسم والسعر والصور والمقاسات والمخزون.

## الروابط

- الموقع: https://mazen-dxd.github.io/IRAA/
- المستودع: https://github.com/Mazen-dxd/IRAA
- الهوية البصرية في Figma: https://www.figma.com/design/plRF5obagdz2RcdwIP4Odz

## إدارة المتجر

تُضاف المنتجات المعتمدة إلى `products.json` مع صورها داخل `images/`. بعد وجود بيانات حقيقية، تظهر بطاقات المنتجات واختيارات المقاس واللون والحقيبة تلقائياً. دليل الأسعار والمخزون وإرسال الطلب موجود في [STORE-SETUP.md](STORE-SETUP.md).

تفتح الحقيبة رسالة واتساب جاهزة بطلب الزبونة لتأكيده يدوياً. لا ينفذ الموقع دفعاً إلكترونياً أو حجزاً تلقائياً للمخزون.
